# Landing-page hero art

`web/hero.png` is the page's splash image: a contemporary tower entrance
in the visual language of SimTower's 1994 splash screen (canopy sign
letters, entrance glass with the lobby glowing through, globe pendants,
"Inspired by Yoot Saito" plaque). It is original art — no Maxis assets
ship with the page.

Current version: generated by Jonah with an image model (2026-08-14),
then run through the 1994-ifier below — center-crop to 4:3, downscale to
640x480, Bayer 4x4 ordered dither, adaptive 96-color palette, saved as
an indexed PNG. `hero-source.jpg` is a compressed copy of the source
generation for future re-derivation.

`hero.svg` is the earlier hand-drawn vector take on the same brief, kept
as an editable fallback (its pipeline is in the git history of this
README).

Re-derive hero.png from a new source image (needs PIL + numpy):

    python3 - <<'PY'
    from PIL import Image
    im = Image.open('SOURCE.png').convert('RGB')
    w, h = im.size; t = 4/3
    if w/h > t: nw = int(h*t); im = im.crop(((w-nw)//2, 0, (w-nw)//2+nw, h))
    else:       nh = int(w/t); im = im.crop((0, (h-nh)//2, w, (h-nh)//2+nh))
    im.resize((640,480), Image.LANCZOS).save('/tmp/raw.png')
    PY
    python3 web/art/dither.py /tmp/raw.png /tmp/d.png 96 12
    python3 - <<'PY'
    from PIL import Image
    Image.open('/tmp/d.png').convert('RGB').quantize(96, dither=Image.Dither.NONE) \
        .save('web/hero.png', optimize=True)
    PY
